# Radar Gratuit sur GitHub Pages

Le site publié est statique : `index.html`, `style.css`, `static-api.js` et `app.js` tournent dans le navigateur. Les préférences, favoris et modifications sont stockés localement dans le navigateur ; ils ne sont pas synchronisés entre appareils.

Le workflow `.github/workflows/catalog.yml` exécute `scripts/update-catalog.mjs` au changement du scanner, manuellement et environ toutes les dix minutes. Il analyse les sources prédéfinies à l'aide de `server.js`, puis met à jour `data/catalog.json` lorsqu’il détecte un changement et au moins une fois par heure si tout reste identique. Le site lit le catalogue public à partir de la branche `main` sur `raw.githubusercontent.com` ; ainsi les données sont actualisées même si une modification faite par GitHub Actions ne déclenche pas une nouvelle publication Pages. Si ce fichier ne répond pas, il utilise le catalogue inclus dans la publication Pages. L'actualisation peut être retardée ou échouer selon les permissions GitHub Actions, la disponibilité des sources ou les limites de GitHub.

Le catalogue écarte certains achats et prix évidents, mais ce filtrage est imparfait. Les résultats sont des pistes : le flux est lu, mais pas les pages liées. Les cinq critères de gratuité exigent une vérification et une preuve manuelles. Les codes ne sont pas testés. Des sources peuvent bloquer le scanner ; leurs erreurs et dates sont affichées. La recherche Web s'ouvre dans Google Actualités et ne remplit pas automatiquement le catalogue. Ajouter des sources et analyser des URLs à la demande nécessite la version locale ; GitHub Pages ne peut pas exécuter le serveur Node.js. Les alertes apparaissent seulement lors d'une visite et restent sur l'appareil. La surveillance et les notifications locales ne sont pas une garantie d'envoi en arrière-plan.

La version locale originale figure toujours dans `server.js` et la documentation `LISEZ-MOI.md`. Pour l'exécuter depuis ce dépôt, placez `index.html`, `style.css` et l'ancienne interface locale dans un dossier `public` ; les fichiers Web actuels sont adaptés à Pages et utilisent le stockage navigateur.

Les sources Canada / Québec sont repérées par leur public cible : cela ne confirme pas l’admissibilité individuelle d’une offre. Le filtre correspondant porte sur la provenance, pas sur les pays garantis. Les horaires GitHub Actions sont approximatifs et peuvent être retardés ; l’onglet Sources indique la dernière publication. Les navigateurs ouverts consultent le catalogue environ toutes les dix minutes lorsque la page est active.
